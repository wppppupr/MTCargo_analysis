## 3. Results

### 3.1 貨物の方向追従と結合効率は R_c/ξ でそろう

MT カーペット上の貨物が、足元の流れにどれだけ追従するかを 2 つの量で評価した。
貨物速度 **v** と、貨物の足元（半径 R_c の円内）で平均した流れ ⟨**u**⟩_{R_c} の間の角度を ψ とし、
方向追従を cos ψ = **v**·⟨**u**⟩/(|**v**||⟨**u**⟩|) で、
結合効率を η = Σ v_∥ / Σ |⟨**u**⟩|（v_∥ = **v**·⟨**u**⟩/|⟨**u**⟩|）で定義した（Δt = 4 s）。
横軸には、動画ごとに求めた ξ で R_c を割った R_c/ξ を用いた。

cos ψ と η はどちらも R_c/ξ とともに単調に下がった（Fig. 1、Table 1）。
最小の貨物（2R_c = 0.63 µm、R_c/ξ ≈ 0.06）では cos ψ = 0.39 [0.35, 0.44]、η = 0.52 [0.46, 0.58] だった。
一方、最大の貨物（20 µm、R_c/ξ ≈ 3.1）ではどちらもほぼ 0 になった（cos ψ = −0.04 [−0.12, 0.04]、η = 0.02 [0.01, 0.04]）。
括弧内はビーズ単位のブートストラップによる 68% 信頼区間。
動画単位（n = 22）の Spearman 順位相関は、cos ψ で ρ = −0.78（p = 2×10⁻⁵）、η で ρ = −0.74（p = 9×10⁻⁵）だった。
ビーズ数 2 個以上の動画（n = 18）に絞っても、相関は有意なまま残った（ρ = −0.70 と −0.61、p < 0.01）。

R_c/ξ で並べたときに注目すべき点は、5 µm と 7 µm の順序である。
5 µm の動画では ξ が短い（2.9–4.2 µm）ため、R_c/ξ（≈ 0.82）は 7 µm（≈ 0.39）より大きくなる。
cos ψ も 5 µm（0.11）のほうが 7 µm（0.19）より低かった。
つまり、サイズ別の 6 点は R_c ではなく R_c/ξ の順に並ぶ（cos ψ で ρ = −1.00、η で ρ = −0.94）。
このことは、追従を決めるのが貨物の絶対サイズではなく、足場の相関長との比であることを示唆する。
ただし、log R_c と log(R_c/ξ) を同時に回帰すると、両者の相関が強いため、どちらの係数も単独では有意にならなかった（§4.3）。

### 3.2 貨物の縁で流れは遅くなる

貨物の縁から距離 r での流速 |**u**|(r) を、フレームごとに取り直した遠方流速 u_∞(t)（r ≥ 20 µm のプラトー）で規格化して調べた。
u_∞ は 1 本の動画の中でも 2–8 倍の幅で揺らいでいた（例：beads5um002 で 0.05–0.40 µm/s）。
それでも、動画全体の u_∞ で規格化した場合と比べて、縁での値はほとんど変わらなかった（多くの動画で差は 0.02 以下）。
したがって、以下の結果が u_∞ の時間揺らぎで生じたものである可能性は低い。

0.63–7.24 µm の貨物では、縁での流速は遠方の 60–84% にとどまり、16–40% 遅くなっていた（Table 2、Fig. 2）。
この低下は r ≈ 3.5ξ までに回復した（|**u**|/u_∞ = 0.98–1.01）。
低下の深さはサイズについて単調ではなかった。
最も浅かったのは 5 µm（16%）で、これは ξ が最も短い条件でもある。
20 µm では逆に、縁の流速が遠方の 1.7 倍に見えた。
これはビーズ自身の像が光学フローに漏れ込んでいる可能性が高く、物理的な加速として解釈すべきではない【要確認】。

### 3.3 縁の遅い領域は 100 s 以上残る

貨物がある時刻 t の位置を固定し、時刻 t + Δt の流れ場で同じ解析をした。
こうすると、遅い領域が貨物について動いているのか、その場に残っているのかがわかる。
縁での低下の深さは Δt = 128 s でも、Δt = 0 での値の 63–93% が残っていた（Table 3）。
指数緩和の時間 τ をはっきり決められたのは 5 µm（τ ≈ 320 ± 280 s）だけだった。
他のサイズで求まったのは、2σ での下限（τ ≳ 30–190 s）だけだった。
遅い領域は、貨物がいる瞬間だけその場で作られているのではなく、流れ場に長く残る構造である可能性がある【要確認：同じ Δt での貨物の移動距離と ξ を比べ、貨物がもうその場にいないことを確かめる】。
この区別は、次節の仮想トレーサーとの比較で検証する。

## 4. Discussion

### 4.1 η の低下の大部分は「向きのずれ」で説明できる

η は、方向の成分（cos ψ）と速さの成分（κ）の積でおおまかに表せる。
0.63–3.37 µm では κ ≈ 0.8–0.95 とほぼ 1 なのに、cos ψ は 0.27–0.39 しかない。
したがって、η が 1 に届かない主な理由は、貨物が流れと違う向きに動いている時間が長いことであり、流れに乗っている間の速さが落ちることではない。
R_c/ξ が大きくなると cos ψ は 0 に近づく。
これは、足元の円の中に向きの違う流れの領域（大きさ ~ξ）がいくつも入り、平均すると打ち消し合うという描像と矛盾しない。

### 4.2 回転（転がり）は主な要因ではない

貨物の下端だけが MT カーペットに押され、球が自由に回転できるとする。
この場合、接点の速度の一部が回転に使われるので、並進速度と接点の速度の比は、壁のないバルクで κ_roll = 4/7 ≈ 0.57 になる。
壁の近く（Goldman–Cox–Brenner, 隙間 δ = 20–200 nm）では 0.33–0.46 まで下がる。
この値はサイズにほとんどよらない。
しかし実測の κ は、0.63–3.37 µm で 0.8–0.95 と、この上限をはっきり上回った。
δ = 50 nm の模型の上限を超えた動画は全体の 81% だった。
また κ は R_c にも R_c/ξ にも有意には相関しなかった（Spearman ρ = −0.21, p = 0.35；ρ = −0.07, p = 0.77）。
したがって、自由な転がりは小〜中サイズの貨物では起きておらず、貨物は回転を拘束されたまま（複数の接点や MT 束への埋まり込みで）平行移動していると考えられる。
面内での回転（z 軸まわり）は、等方な球では並進と結びつかないため、η を直接は下げない。

7.24 µm と 20 µm の κ（0.52 と 0.35）は、転がり模型の値（≈ 0.45）に近い。
大きな貨物では接点が相対的に減り、転がりが部分的に効いている可能性は残る【要確認：大きな貨物での回転を直接測る（非対称ビーズや蛍光マーカー）のが望ましい】。
ただし、そのサイズではもともと cos ψ ≲ 0.2 であり、η の低下全体に占める寄与は小さい。

### 4.3 制御変数は R_c か R_c/ξ か

サイズ別の順序（5 µm と 7 µm の入れ替わり）は R_c/ξ を支持している。
しかし動画単位で cos ψ を log R_c と log(R_c/ξ) に同時に回帰すると、係数は b_R = −0.17 ± 0.18、b_X = −0.07 ± 0.18（R² = 0.50）で、どちらも単独では有意にならなかった。
ξ の動画間の幅（2.9–9.3 µm）は R_c の幅（0.3–10 µm）より小さく、今のデータだけでは 2 つを分けにくい。
同じ R_c で ξ を変えた実験（たとえば MT 濃度やモーター濃度を変える）を行えば、この問題に直接答えられる。

### 4.4 縁の低下は R_c/ξ だけでは決まらない

縁の低下の深さ（16–40%）はサイズについて単調ではなく、cos ψ ほどきれいに R_c/ξ でそろわなかった。
低下が 100 s 以上残ることを考えると、貨物が流れを乱すこと（排除・抗力）と、流されている物体が遅い場所（たとえば欠陥の近く）にたまりやすいこと（サンプリング効果）が、両方効いている可能性がある。
§3.4 の仮想トレーサーとの比較は、この 2 つを分けるための対照実験である。

### 4.5 小さな貨物でも cos ψ ≈ 0.4 にとどまる理由（未解決）

最も小さい 0.63 µm（R_c/ξ ≈ 0.06）でも cos ψ は 0.4 程度で、1 には遠い。
足元の円の中の流れはほぼ一様なはずなので、4.1 の打ち消し合いでは説明できない。
ブラウン運動による揺らぎは、Δt = 4 s では流れによる変位より小さいと見積もられ、これだけでは説明しにくい【要確認：見積もりの数値を本文用に再計算する】。
有力な候補は、貨物が MT に結合した状態と外れた状態を行き来すること（Run / Tumble 解析、HMM 解析と対応）である。
cos ψ を HMM で推定した結合状態ごとに分けて計算すれば、この仮説を直接確かめられる。

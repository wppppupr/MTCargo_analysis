# 🌙 夜間自律研究システム (Overnight Research System)

Claude Code と Gemini（Antigravity）が協調し、深夜に研究コードの改善・解析検証・考察を進める自律ループシステムです。

---

## 💡 今夜の解析要望・リクエストの出し方（3通り）

「今夜はこのスクリプトを解析してほしい」「このプロットを作っておいてほしい」という要望を、以下のいずれかの方法で簡単に出せます。

### 方法 1: メモファイルに書いておく（おすすめ）
リポジトリ直下の [`OVERNIGHT_INSTRUCTION.md`](OVERNIGHT_INSTRUCTION.md) にチェックボックス形式で要望を書いておくだけです：

```markdown
## 🎯 優先タスク
- [ ] plot_velocity_decomposition.py で beads06um と beads20um の速度プロットを比較出力してほしい
- [ ] contrast_analysis.py のキャッシュ保存処理を整理してエラーが出ないようにしてほしい
```
* スクリプトが自動でこのメモを読み取り、実行します。
* 完了したタスクには自動で `- [x]` が付き、完了時刻が記録されます。

### 方法 2: 帰宅時のコマンドライン引数で直接渡す
```bash
cd ~/MTCargo_analysis
./start_overnight.sh --bg -i "plot_velocity_decomposition.py で beads3um を重点的に解析して"
```

### 方法 3: 起動時に対話入力する
引数なしで `./start_overnight.sh` を叩くと、ターミナルで対話的に「今夜やってほしいこと」を聞いてくれます。

※何も指定しなかった場合は、自動的に「直近の差分（`git diff`）から改善点を見つけて進める」モードになります。

## 🛡️ トークン節約 & 翌朝の作業枠温存ガードレール

「翌朝出社後、自身もコーディングエージェントとして快適に使いたい」という最重要要件を満たすため、以下の安全弁を組み込んでいます：

1. **厳格なイテレーション上限（デフォルト 3 回）**
   * 無限ループを防止し、最大 3 サイクルで確実に停止します。
2. **深夜 4 時の自動終了（5時間枠の完全回復）**
   * Claude Code のレートリミット（通常 5 時間枠のローリングウィンドウ）を考慮し、**午前 4 時以降は新規イテレーションを開始せず自動終了**します。
   * これにより、朝 9 時に出社した際には利用枠が 100% 回復した状態で作業を始められます。
3. **エラー修復の深追い禁止（最大 1 回）**
   * コード修正でエラーが発生した場合、自動修復の試行は 1 回に限定。2 回連続で失敗した場合は、トークンを浪費せず即座にスキップし、「翌朝の人間判断リスト」へ回します。
4. **コンパクトなプロンプト設計**
   * 全ファイルをコンテキストに流し込むような無駄な消費を一切行わず、指示内容と直近の差分（`git diff`）のみをピンポイントで渡します。

2. **Git コミット履歴の確認**
   ```bash

   ```

## 📌 宿題（2026-11-06 追加）

result3.md の 4.4 節「$v_\parallel/u_\infty\approx\eta_0(R_c)\,\Phi_\mathrm{fp}(R_c/\xi)$」を固めるための解析です。実際のタスクは [`OVERNIGHT_INSTRUCTION.md`](OVERNIGHT_INSTRUCTION.md) に【4.4】としてチェックボックスで書いてあります（夜間ループはそちらを読みます）。

背景：
- 速度の指標を $\eta$ から $v_\parallel/u_\infty(t)$ に移す。$\eta$ は分母が足印の流れなので雑音が大きく、貨物の像の写り込みも入る。
- $\Phi_\mathrm{fp}$ は、円環上で $C(r)=e^{-r/\xi}$ を平均した式からフィットなしで予測でき、0.63–7.24 µm で実測と 0.1 程度以内で合う（下書き：`scratch/phi_ring_model_draft.py`）。
- 伝達率 $\eta_0=v_\parallel/u_\infty\div\Phi_\mathrm{fp}$ は 0.63–3.37 µm で約 0.3、5.00–7.24 µm で 0.16–0.20 と段差的に下がり、$k_\mathrm{SR}$ の段差と同じ位置にある。

宿題：
1. 円環平均の予測曲線を `vpar_and_phi_vs_rc_over_xi.png` に重ね、動画ごとの実測と予測を表にする。
2. $\eta_0$ の階層ブートストラップ。2 群（≤3.37 µm と ≥5.00 µm）の差、$R_c$ と $R_c/\xi$ のどちらに回帰した方がよいか。
3. $u_\infty(t)$ 版で $v_\parallel/u_\infty$ と $\eta$ の雑音を比べる。
4. 時間窓ごとの $\xi(t)$ で予測した $\Phi_\mathrm{fp}(t)$ と実測の比較（同じ動画の中でも式が成り立つか）。
5. 足印の円環の内径と幅を変えても、予測と実測の一致が保たれるか。

注意：result3.md 本体は書き換えない。数値は MORNING_REPORT.md に表で書く。図と CSV は `figure/<タスク名>/` に置く。
